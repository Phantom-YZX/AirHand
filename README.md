# 隔空手控 / AirHand

用一只手，隔空操作安卓手机。通过前置摄像头在本地识别手部动作，借助系统无障碍服务完成点击、滑动、长按与拖拽，无需 Root。

本仓库用于 APK 分发、使用说明和更新记录；项目源码未公开。请从本仓库的 [Releases](https://github.com/Phantom-YZX/AirHand/releases) 下载 APK。仓库自动生成的 Source code 压缩包只包含公开说明。

## 选择版本

| 版本 | 系统与架构 | 识别方式 |
| --- | --- | --- |
| 普通版（一般设备优先） | Android 8.0+，ARM64 / ARMv7 | GPU 优先，失败回退 CPU |
| NPU 实验版 | Android 12+，ARM64；目前针对 SM8850 / HTP V81 | 高通 QNN / NPU，失败回退 GPU / CPU |

NPU 版已在 REDMI K90 Pro Max 试用，不代表兼容全部安卓 NPU。两个版本包名相同，不能作为两个独立应用同时安装。

## 开始使用

1. 固定手机，让前摄朝向自己，保持正常光照与整只手可见，优先在脸侧操作。
2. 按应用说明允许相机权限，手动开启“隔空手控”无障碍服务；建议允许通知，以便查看状态和停止。
3. 完成操作区域校准和四项手势练习，再启动跨应用控制。
4. 移动食指控制光标；短捏合后松开点击；捏住移动滑动；原地保持长按后继续移动可拖拽。

同时短按音量加和减可暂停/恢复。设备支持接近传感器并启用相应选项时，也可在正面顶部短暂靠近后移开来切换。暂停关闭前摄；恢复后先张开手。无手持续约两秒后，启用的自适应采集会降低相机采集帧率。

识别在手机本地完成，不保存或上传摄像头画面。App 不申请联网权限；项目主页由外部浏览器打开。详见 [隐私与权限](PRIVACY.txt)、[安装与签名说明](INSTALL.md)、[更新记录](CHANGELOG.md) 和 [第三方声明](THIRD_PARTY_NOTICES.md)。
